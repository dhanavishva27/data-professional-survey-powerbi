# Data Professional Survey Analysis 📊

## 📌 Project Overview
This Power BI project analyzes survey data of data professionals to understand salary trends, job roles, and satisfaction levels.

## 🧹 Data Cleaning
- Removed duplicates and missing values
- Standardized data formats
- Transformed raw dataset using Power Query

## 📊 Key Insights
- Salary comparison across roles
- Work-life balance analysis
- Country-wise distribution of professionals

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
